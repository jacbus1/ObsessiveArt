# ObsessArt

**讓想法彼此連結的個人空間。**

筆記、視覺白板與知識關係圖，共用同一份工作空間。GitHub repo 名稱為 `ObsessiveArt`，產品名稱為 **ObsessArt**。

[English](README.md) · [架構](docs/ARCHITECTURE.md) · [部署與備份](docs/DEPLOYMENT.md) · [測試紀錄](docs/TEST_REPORT.md)

> **目前為 v0.1 個人測試版。** 已有可運行程式，不只是介面展示；但尚未完成 production 或多人協作驗收。重要資料必須另存獨立備份。

## 本機啟動

需要 Node.js 22.16 或以上；部署時請使用仍受維護並已更新安全修補的版本。實際已測試的版本列於測試報告。

```bash
git clone https://github.com/jacbus1/ObsessiveArt.git
cd ObsessiveArt
git switch feat/obsessart-core # PR 合併前使用此分支
npm start
```

瀏覽器開啟 `http://127.0.0.1:4173`。不需要安裝 runtime 套件、提供 API key 或設定第三方資料庫。使用 Node 內建 SQLite；已測試的 Node 22 會顯示此模組的 experimental 警告。取得程式與 runtime 後，使用本機版本不依賴互聯網，但本機伺服器必須保持運行。

首次啟動會建立一個虛構示例工作空間。資料保存在 `./data/obsessart.sqlite`，不會上傳 GitHub。瀏覽器中的復原草稿只是輔助，不能取代獨立備份。

## 已實作

| 範圍 | 功能 |
| --- | --- |
| 筆記 | Markdown 編寫／閱讀、穩定內部連結、標籤、來源網址、全文搜尋、反向連結、垃圾桶與還原 |
| 白板 | 共用筆記卡片、拖曳、調整大小、Shift 多選、平移、縮放、適合畫面、箭頭、結構操作復原／重做 |
| 關係圖 | 由筆記連結產生圖譜，可聚焦所選筆記；白板箭頭不會自動變成知識關係 |
| 儲存 | SQLite WAL、同步持久提交、版本檢查；舊分頁不能靜默覆蓋新版本 |
| 備份 | 最近 50 個工作空間快照、含校驗碼的原生 JSON 備份、單篇 Markdown 匯入／匯出、SQLite 線上備份工具 |
| 存取 | 預設限本機 loopback；可設定擁有人密碼；production 模式要求密碼與 HTTPS origin |
| 介面 | 英文／繁體中文、響應式編輯器、手機尺寸排版、搜尋與儲存快捷鍵 |

**同一張筆記可以出現在多個白板，不會複製正文。** 修改其中一處，其他位置引用同一份內容；從白板移除卡片或刪除白板，不會刪除筆記。筆記進入垃圾桶後保留位置，還原時重新顯示。

「連結筆記」插入 `[[穩定識別碼|顯示文字]]`，改名不會斷鏈。`[[標題]]` 只在標題唯一時解析。使用「連接卡片」依次選兩張卡建立箭頭；再選同一方向會移除該箭頭。

## 儲存狀態與備份

狀態按鈕會區分等待儲存、伺服器確認完成及儲存失敗。按下可匯出復原草稿、重試或明確載入伺服器版本。遇到其他分頁的新版本時，不會自動覆蓋。

「匯出」下載目前工作空間的原生備份，包含通過資料驗證、但尚未同步的修改；不包含歷史版本、密碼或瀏覽器復原資料。「匯入」經確認後會取代目前工作空間。復原草稿 JSON 供手動核對，不是一般可直接匯入的備份。

```bash
npm run backup
npm run backup -- ./backups/manual.sqlite
```

SQLite 備份包含保留中的歷史版本。請把備份另存其他裝置，並按部署文件實際測試還原。

## 驗證

```bash
npm run check
npm test
```

初次紀錄：**61 項 Node 測試通過；9 項隔離渲染介面測試通過**。介面測試因執行環境限制，使用本機 API 請求橋接與模擬的瀏覽器復原儲存；不等於已驗證真實網頁導覽、cookie、CSP 或 IndexedDB。完整瀏覽器模式及執行方式見英文 README 與測試報告。不能因為存在 CI 設定，就視為 CI 已成功。

## 尚未包含

即時多人協作、分級權限、雲端帳戶、附件、PDF 批註、自由手繪、PWA 離線重開、資料夾同步與 AI provider 接口均未完成。不宣稱端到端加密。Markdown 僅支援明確的安全子集，不渲染任意 HTML、嵌入內容或外部圖片。

目前上限為 2 MB 工作空間、1,000 則筆記、100 個白板、每板 1,000 個卡片位置、每則筆記 100,000 字元。圖譜最多預覽 250 則符合條件的筆記。這些是安全上限，**不是已驗證的效能數字**；目前整個工作空間會載入記憶體。
