# ObsessiveArt

[English](README.md) · [架構](docs/ARCHITECTURE.md) · [安全說明](SECURITY.md)

**筆記、白板、知識圖譜，共用同一份資料。這個 repo 包含可執行程式，不只有研究文件。**

這是獨立實作的單人、本機優先網頁應用，借鏡 Obsidian、Miro、Heptabase 的工作流；與三者沒有隸屬關係，也不包含它們的專有程式碼。

## 立即使用

需要 Node.js 22 或以上：

```sh
git clone https://github.com/jacbus1/ObsessiveArt.git
cd ObsessiveArt
npm start
```

打開 **http://localhost:4173**。**不用 `npm install`，不用 API key、帳號或外部資料庫。** 不要直接雙擊 `index.html`。以後請使用相同網址、連接埠及瀏覽器。

## 資料安全與界線

內容只儲存在**目前瀏覽器、目前網址**。推送程式碼到 GitHub，不會把你的筆記推送上去。程式沒有分析追蹤、外部 CDN、AI 呼叫或上傳筆記的 API。

**清除網站資料、私密瀏覽、換裝置或硬碟故障，都可能令本機內容無法取得。** 請定期在「資料與設定」下載完整 JSON，確認檔案確實保存。Markdown ZIP 只是可讀匯出，不是完整備份；不要拿它代替 JSON 還原。沒有應用程式層的加密保護。

不同網址／連接埠／瀏覽器不會自動同步。由 localhost 搬到 GitHub Pages，需要自行匯出再還原 JSON。同時開兩個分頁時，過期寫入會被拒絕；若出現停止儲存提示，先下載未儲存內容，再重新載入，避免覆蓋。

## 版本狀態

**這是可以使用的 v0.1.0 單人本機版，不是完整複製三款產品，也不是已完成企業正式上線認證。** 暫未包含多人協作、跨裝置同步、帳號權限、AI、OCR、手繪、完整 PDF 閱讀／高亮定位、任意富文本區塊、Miro／Heptabase 無損匯入。PDF 附件可下載，沒有假稱已解析正文。Markdown 支援子集，HTML 只會顯示為文字，不會執行。

白板復原／重做是本次開啟期間的結構操作記錄；開始文字編輯時會清除，避免舊的白板快照覆蓋新正文。文字欄位使用瀏覽器原生撤銷，較早正文可從「版本記錄」還原。區段框拖動時帶動完全包在框內的卡片，並非永久群組關係。

安全上限：5,000 筆記、150 白板、總共 5,000 白板物件、200 附件、每個附件 8 MiB、每則筆記 250,000 字元、正文及歷史合計 16 MiB、完整備份 40 MiB。**上限不代表已通過相同規模的效能測試。**

## 放上網站

```sh
npm run check
npm test
npm run build
```

把 `dist/` 放到支援 HTTPS 的靜態主機即可。所有資產路徑都是相對路徑，可放在 GitHub repo 子路徑。

GitHub Pages：**Settings → Pages → Source 選 GitHub Actions**；再到 **Actions → Deploy to GitHub Pages → Run workflow**。這個部署工作流程需要手動啟動，不能把 push 完成說成網站已上線。網站只提供應用程式，每位使用者在自己的瀏覽器保有獨立資料。

離線快取更新時，先確認儲存完成，關閉所有 ObsessiveArt 分頁再重新開啟。不要為更新程式而直接清除網站資料。

## 測試

`npm test` 執行核心與安全測試；`npm run check` 檢查語法；`npm run build` 產出靜態站。GitHub Actions 額外執行真正的 Chromium、IndexedDB、備份還原及離線重開測試，並上傳截圖與報告。請以該 commit 的實際 Actions 結果為準，不把「已寫測試」當「已通過」。
